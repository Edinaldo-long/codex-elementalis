# 🧙‍♂️ Codex Elementalis

> Plataforma web interativa desenvolvida como parte de um ecossistema educacional gamificado (RPG), projetada para gerenciar elementos, progressão e consultas de jogadores/estudantes de forma visual e intuitiva.

🔗 **Deploy em produção:** [https://codex-elementalis.web.app](https://codex-elementalis.web.app)

---

## 📌 Visão Geral do Produto

O **Codex Elementalis** foi criado para transformar o aprendizado em uma experiência de RPG (Role-Playing Game). A aplicação funciona como a central de regras, grimório e painel de controle do universo do jogo, permitindo que os usuários consultem atributos, habilidades e dados de mecânicas elementais em tempo real.

### 🎯 Problema que Resolve
Em sistemas de aprendizagem baseados em jogos (GBL), o excesso de fichas em papel e tabelas dispersas dispersa a atenção dos participantes. O Codex centraliza:
- Consulta rápida a tabelas elementais e atributos.
- Interface imersiva e responsiva adaptada ao universo narrativo do jogo.
- Acesso leve e sem fricção direto pelo navegador (desktop e mobile).

---

## ⚙️ Principais Funcionalidades

- **📖 Consulta de Elementos & Atributos:** Visualização dinâmica dos dados estruturados do sistema de RPG educacional.
- **⚡ Interface Responsiva & Temática:** Layout estilizado com identidade visual imersiva (dark fantasy/medieval), otimizado para carregamento instantâneo.
- **🔒 Autenticação & Acesso:** Integração com fluxo de acesso para participantes do ecossistema educacional.
- **☁️ Hospedagem com CDN Global:** Servido via infraestrutura Firebase Hosting com SSL/TLS automático e baixa latência.

---

## 🛠️ Arquitetura & Tecnologias

A aplicação foi estruturada prezando por simplicidade arquitetural, baixo consumo de memória e alta performance de renderização no cliente:

- **Frontend Core:** HTML5 Semântico, CSS3 Moderno (Flexbox/Grid, variáveis de tema customizadas) e JavaScript Vanilla (ES6+).
- **Hospedagem & Infraestrutura:** [Firebase Hosting](https://firebase.google.com/) (Google Cloud) com roteamento estático e entrega via CDN.
- **Controle de Versão:** Git & GitHub com versionamento semântico.
